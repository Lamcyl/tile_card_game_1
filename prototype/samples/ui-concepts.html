Tilewhist — six directions for the interface

The same fight is drawn six ways: three enemies (the middle one is the boss), a 3×3 board with one blocked cell and a red sandwich, three tiles in hand, and Attack. These are look-and-feel studies only; the real screen would keep every feature it has today.

The research flagged these AI-default habits, so every concept avoids them:

  • the Inter font everywhere, and font sizes taken from the default scale;
  • the same 16–24px rounded corner on everything, with cards nested in cards;
  • purple-to-blue gradients, with the brand colour on every element;
  • everything centred, or three equal cards in a row;
  • shadow, border and tint used on the same card;
  • a stock icon inside a coloured circle;
  • dark mode made by inverting the light colours.
