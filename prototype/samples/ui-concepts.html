Tilewhist — six directions for the whole interface

The game's tiles stay exactly as they are (the coloured squares here). Each direction is shown on three screens: the main screen with the map, the Tiles screen and the stage-cleared result. They change the frame around the tiles: the background, lettering, buttons, panels, lists, the map and navigation, and how each screen is laid out.

Each one avoids the usual AI-made look: the Inter font, the same rounded corner on everything, cards nested in cards, purple gradients, everything centred, and icons inside coloured circles.
